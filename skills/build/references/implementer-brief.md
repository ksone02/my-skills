# 구현자 작업 설명서 형식

파일 하나로 만들어 경로를 넘겨요(`.git/my-skills/brief-T<n>.md`, `.git` 안이라 커밋되지 않아요).

```
# T<n>: <작업 이름>
계획: <계획 경로>  명세: <명세 경로>
전체 제약: <계획의 전체 제약 그대로 복사>

## 할 일
<계획의 해당 작업 전문>

## 다른 작업과 주고받는 것
<앞 작업이 만든 이름·형식, 이 작업이 만들어야 하는 이름·형식>

## 규칙
- 시험을 먼저 쓰고 실패를 확인한 뒤 구현해요.
- 계획에 없는 파일을 나누거나 기능을 더하지 않아요. 필요해 보이면 `걱정 있음`으로 보고해요.
- 끝나면 시험 명령과 결과를 붙여요.

## 보고 형식
상태: 완료 | 걱정 있음 | 막힘 | 맥락 필요
바꾼 파일:
시험 명령과 결과:
걱정·막힌 곳(있으면):
```
