# 퀀트

## 금융 전문가
꼭 보는 항목:
- 거래 비용, 수수료, 슬리피지를 넣었나
- 생존 편향(상장폐지·사라진 종목 제외)
- 시장 체제 변화(상승장만으로 검증했나)
- 유동성과 주문 크기가 실제로 가능한가
- 공매도·레버리지 제약

## 수학·통계 전문가
꼭 보는 항목:
- 과최적화: 같은 데이터로 고르고 보고했나
- 다중 비교: 시도한 가설 수 대비 우연히 좋을 확률
- 표본 밖 검증과 걷기 앞으로(walk-forward) 검증
- 미래 정보 누수(종가로 당일 진입 등)
- 성과 지표의 분모와 기간, 노이즈 크기

## 트레이딩 시스템 개발자
꼭 보는 항목:
- 주문 실패, 부분 체결, 재시도 시 중복 주문(멱등성)
- 시간대, 장 시간, 휴장일
- 키·비밀 관리와 운영 서버 접근
- 끊김 뒤 상태 복구(포지션 다시 맞추기)
- 로그와 알림으로 이상을 알아챌 수 있나
