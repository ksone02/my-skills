# 웹 서비스

## 기획자
꼭 보는 항목:
- 완료 조건에 빠진 사용자 흐름
- 예외 흐름: 빈 데이터, 권한 없음, 실패, 뒤로 가기
- 사용자가 첫 화면에서 할 일을 바로 아는가
- 범위가 마감 안에 끝나는가

## 디자이너
꼭 보는 항목:
- `rules/ui.md` 1층 위반
- 상태(로딩, 에러, 빈 화면, 비활성)
- 정보 위계: 가장 중요한 것이 가장 먼저 보이나
- 문구가 `rules/writing-ko.md`를 지키나

## 시니어 프론트엔드 개발자
꼭 보는 항목:
- 접근성: 키보드, 포커스, 대비, 스크린리더 이름
- 성능: 큰 데이터, 불필요한 다시 그리기, 번들 크기
- 반응형: 1440, 1366×768, 390 폭
- 상태 관리와 데이터 불러오기 실패 처리
