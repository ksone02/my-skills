# finish

## 목적
"다 됐다"는 말이 실제 결과물과 맞는지 마지막으로 확인하고 작업을 깔끔하게 닫아요.

## 입력
- 명세와 진행 기록(있으면).

## 산출물
- 마무리 보고: 완료 조건 최종 표, 계획과 다르게 한 판단 목록(진행 기록의 `판단:` 줄 전부), 보류한 지적, 남은 위험.

## 실행 순서
1. 완료 조건을 실제 결과물로 한 번 더 확인해요(시험 전체, 화면이면 측정). 이전 결과를 재사용하지 않아요.
2. 전체 시험·린트 명령을 돌리고 결과 줄을 보고에 붙여요.
3. 임시 파일(`.my-skills/`, `.measure/`)을 지워요.
4. 진행 기록의 `판단:`·`보류:` 줄을 모아 보고해요.
5. 사용자가 정한 결정이 있었으면 `handoff decide`로 결정 기록을 남기자고 한 줄로 안내해요.
6. 커밋·푸시·PR은 사용자가 시킨 것만 해요. 시키지 않았으면 무엇이 남았는지만 알려요.

## 하지 않는 것
- 새 수정. 문제가 보이면 `check`로 돌아가자고 알려요.

## 하지 말아야 할 것
- 확인 명령 없이 "완료"라고 쓰기.
- 사용자 확인 없이 푸시, 병합, 배포.
