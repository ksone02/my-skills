# 한국어 글 규칙

## 쉬운 말
- 전문 용어를 피하고, 써야 하면 처음 한 번 풀어 써요.
- 숫자마다 무엇을 잰 값인지, 단위, 어떻게 계산했는지를 붙여요. 퍼센트는 무엇의 몇 퍼센트인지까지.
- 설명하려고 비유를 지어내지 않아요.
- 민감한 주제(고립, 건강 등)는 사람 수가 아니라 다른 곳·다른 나이대와 비교한 상대적 경향으로 말해요.

## 문구 원칙 (화면·안내문)
- 사용자가 하는 일을 주어로 써요. "시스템이 처리 중입니다" 대신 지금 무엇을 기다리는지.
- 얻는 것으로 말해요. 손실·불안을 자극하지 않아요.
- 확인 가능한 사실로 써요. 사용자의 감정을 대신 단정하지 않아요.
- 한 문장에 조건과 수치를 몰아넣지 않고 나눠요.
- 제목·부제·본문에서 같은 말을 표현만 바꿔 되풀이하지 않아요.
- 에러는 원인과 다음 행동을 같이 말해요.
- 버튼에는 눌렀을 때 일어나는 일을 써요("확인" 대신 "신청하기").
- 존댓말 수준과 숫자 표기를 화면 전체에서 맞춰요. 한 화면에 언어를 섞지 않아요.

## 자리별 말투

| 자리 | 말투 |
|---|---|
| Notion·요약 문서 | "~함/~임", 짧은 첫 줄 + 들여쓴 대시 목록 |
| README·화면 문구 | 해요체, 결론 먼저, 짧은 문장 |
| 사용자에게 하는 답변 | 짧은 한국어, 결론 먼저 |
