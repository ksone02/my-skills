# my-skills Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 설계 문서대로 Superpowers를 대체할 개인 Claude Code 플러그인 `my-skills`(스킬 14개, 규칙 파일, 작은 스크립트 6개, 선택형 훅, 시험 묶음)를 만든다.

**Architecture:** 저장소 루트가 곧 플러그인이자 마켓플레이스다(`.claude-plugin/plugin.json` + `marketplace.json`, source `./`). 스킬은 `skills/<이름>/SKILL.md`에 짧게 두고 긴 기준은 `rules/`와 `skills/<이름>/references/`로 뺀다. 결정적으로 해야 하는 일(파일 거르기, 외부 모델 호출, CLAUDE.md 블록 설치, 위험 명령 확인, 브라우저 측정, 토큰 집계)은 Python 스크립트로 두고 pytest로 시험한다. 스킬 파일 자체는 `tests/test_skills.py`가 형식을 검사한다.

**Tech Stack:** Python 3.12(표준 라이브러리만, 측정 스크립트만 Playwright), uv, pytest 8.3.4, Playwright for Python 1.49.1(측정 스크립트 전용, 선택), Claude Code 플러그인 형식.

**Spec:** `docs/superpowers/specs/2026-11-01-skillset-design.md` (실행자는 이 계획과 함께 반드시 읽는다. 스킬 본문의 내용 요구는 대부분 설계 문서 4장에 있다.)

## Global Constraints

- 모든 `SKILL.md` frontmatter: `name`(디렉터리 이름과 같음), `description`(한국어 한두 문장), `disable-model-invocation: true`. 예외 없음.
- 모든 `SKILL.md` 본문은 다음 6개 `##` 절을 이 순서로 가진다: `## 목적`, `## 입력`, `## 산출물`, `## 실행 순서`, `## 하지 않는 것`, `## 하지 말아야 할 것`.
- `SKILL.md` 본문(frontmatter 제외)은 1,500단어 이하. 넘치는 내용은 `references/`로.
- 스킬·규칙 본문은 한국어. 쉬운 말, 숫자는 단위와 함께. 긴 줄표(—) 남발 금지(규칙 파일 자신이 `rules/writing-ko.md`를 지킨다).
- 규칙은 한 곳에만: 같은 규칙 문장을 두 파일에 쓰지 않고 `rules/<파일>.md`를 상대 경로 링크로 가리킨다.
- 세션 시작 훅을 만들지 않는다. 훅은 `hooks/hooks.json`의 PreToolUse(Bash) 하나뿐이고 상태 파일이 없으면 아무것도 하지 않는다.
- 하위 에이전트를 띄우라고 지시하는 모든 스킬 문장에는 모델(haiku/sonnet/opus)을 명시한다. 기준은 `rules/models.md`.
- 외부 모델(Codex, DeepSeek)로 보내는 모든 경로는 `scripts/safe_files.py`와 `scripts/ext.py`를 거친다.
- 외부 대체 시 결과 문구: `Codex 사용 불가, Claude로 검증` / `DeepSeek 사용 불가, Claude로 조사`.
- 브라우저 측정 폭: `1440x900`, `1366x768`, `390x844`. 스크린샷 비평 최대 3회.
- 수정 반복 상한 3회, 4회째부터 한 등급 위 모델.
- Python 스크립트는 표준 라이브러리만 쓴다(`measure.py`의 Playwright 제외). 실패해도 예외로 세션을 깨지 않고 상태 값을 돌려준다.
- 다른 저장소에서 가져온 문장이 있는 파일은 맨 아래 `출처:` 줄을 달고, `NOTICE.md`에 원본 저작권을 모은다.

## Review Focus

1. `always.py install`을 두 번 돌리거나, CLAUDE.md가 없거나, 사용자가 블록 바깥을 고쳐 둔 경우: 블록은 하나만 있고 바깥 내용은 한 글자도 바뀌지 않아야 한다. → Task 3 시험.
2. 보낼 파일 목록에 심볼릭 링크, 중첩된 `data/` 폴더, 바이너리, `sk-`/`AKIA` 같은 키 문자열이 든 파일이 섞인 경우: 전부 빠지고 뺀 이유가 남아야 한다. → Task 4 시험.
3. `codex`/`aside`가 설치 안 됨, 시간 초과, 0이 아닌 종료 코드, 사용량 한도 문구 출력: 예외 없이 `status="unavailable"`과 이유를 돌려줘야 한다. → Task 5 시험.
4. guard 훅에 잘못된 JSON이 들어오거나 상태 파일이 없을 때: 아무 출력 없이 종료 코드 0(세션을 막지 않음). → Task 6 시험.
5. 세션 기록 jsonl에 usage 없는 줄, 깨진 줄, 하위 에이전트 줄이 섞인 경우: 건너뛰고 합계는 정확해야 한다. → Task 8 시험.

### Task 5: `scripts/ext.py` (Codex / DeepSeek 호출과 대체 신호)

**Files:** Create `scripts/ext.py`, `tests/test_ext.py`

**Interfaces:**
- Consumes: `safe_files.select`, `safe_files.external_banned`.
- Produces:
